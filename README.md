# CONÓCETE
Recorrido interactivo de autoconocimiento emocional para estudiantes de grado décimo (HTML5 + CSS3 + JavaScript, sin servidor ni dependencias).

## Estructura
```
index.html        Pantallas: portada, elección de aspectos, preguntas, resultado, recursos
css/styles.css    Diseño responsive (móvil, tableta, computador)
js/data.js        Preguntas, textos y recursos (editable)
js/logic.js       Procesamiento de respuestas y categorías
js/app.js         Interfaz y navegación
docs/DOCUMENTACION.md   Documentación técnica del proyecto
```

## Publicar gratis en GitHub Pages
1. Crea una cuenta en github.com y pulsa **New repository** (nombre: `conocete`, público).
2. Pulsa **uploading an existing file** y arrastra TODO el contenido de esta carpeta (incluida `.nojekyll`). **Commit changes**.
3. Ve a **Settings → Pages**. En *Source* elige **Deploy from a branch**, rama **main**, carpeta **/ (root)**, y **Save**.
4. En 1–3 minutos tu enlace público será `https://TU-USUARIO.github.io/conocete/`.

Para probar en tu computador: abre `index.html` con doble clic.
